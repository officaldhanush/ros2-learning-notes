# ROS 2 Learning Notes & Simulation Scripts

This repository contains beginner-friendly Python scripts and notes focused on **ROS 2 (Robot Operating System)**, **Gazebo simulation**, and mobile robot navigation concepts.

## 📂 Files Included

* **`simple_robot_mover.py`**: A basic ROS 2 Python node that publishes linear velocity commands (`/cmd_vel`) to make a simulated robot (such as TurtleBot3) move forward[cite: 1].

## 🚀 Key Topics Covered
* **ROS 2 Architecture:** Nodes, publishers, and topics (`/cmd_vel`)
* **Gazebo Simulation:** Testing robot behavior in a 3D physics environment
* **SLAM & Navigation:** Mapping environments and navigating autonomously using Nav2

## 🛠️ Tech Stack & Tools
* Python 3
* ROS 2 (Humble / Iron / Jazzy)
* Gazebo Simulator & TurtleBot3
